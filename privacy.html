Privacy Policy

Last updated: 13 October 2026

Atlas is a private, single-user personal assistant. It is operated by Thomas Southwell for his own use and connects only to his own Google account. This policy explains what Google data Atlas accesses, and how it is used, stored and protected.

Google data Atlas accesses

  • Gmail, read-only (gmail.readonly): reads messages to summarise the inbox, sort new email by importance, and track replies Thomas is waiting on.
  • Google Calendar, read-only (calendar.readonly): reads events for the daily brief and meeting preparation.
  • Gmail, send (gmail.send): sends an email only after Thomas has approved that specific email.
  • Calendar events (calendar.events): creates or changes an event only after Thomas has approved that specific change.

How the data is used

Google data is used only to provide Atlas's assistant features to Thomas. It is not used for advertising, it is not sold, and it is not used to build profiles of anyone.

To write summaries and sort email, Atlas sends the relevant email and calendar text to Anthropic's Claude AI service. Anthropic processes that text to produce a response, as described in Anthropic's privacy policy. Google data is not shared with anyone else.

Storage and security

  • Atlas runs on Thomas's own computer. Sign-in tokens, summaries and task data are stored only on that computer.
  • Atlas does not keep a copy of the mailbox. It keeps only short summaries and notes it creates, such as the daily brief.
  • Access to Atlas's web interface is password-protected and limited to Thomas.

Removing access and deleting data

Access can be removed at any time from Google Account → Third-party apps & services. Deleting Atlas's local files permanently removes everything it has stored.

Limited Use

Atlas's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.
